# RaytraycerFromScratch

This project is my implementation of a raytracer based on  [*Ray Tracing in One Weekend*](https://raytracing.github.io/) book series by **Peter Shirley**.

## Stack
- Modern C++
- Visual Studio 2022

Cross platform CMake is planned to be supported.


## Building and Runnning

### `Visual Studio`
1. Open `RaytraycerFromScratch.vcxproj` in Visual Studio
2. Build the solution (__Ctrl+Shift+B__)
3. Run the executable
